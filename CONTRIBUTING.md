# Feedback and changes

Bug reports and feature ideas are welcome through [Issues](https://github.com/Arad-d/ember/issues). Use fictional examples and remove personal records from screenshots.

Report vulnerabilities privately through [Security](https://github.com/Arad-d/ember/security/advisories/new), not through a public issue.

The repository is available for inspection on GitHub and retains an all-rights-reserved copyright notice. It does not have a general open-source license. Please discuss proposed code contributions and reuse permission with the maintainer before submitting substantial work. Third-party dependencies keep their own licenses.

Maintainer changes go through a pull request. The automated secret scan and Flutter checks must pass before merging. Do not introduce deployment credentials or a default connection to a shared database.
